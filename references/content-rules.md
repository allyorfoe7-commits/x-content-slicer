# 内容筛选与切片规则

## 1. 原创主帖判定

优先级从高到低：

1. 作者独立发布、无需前文即可理解的原创主帖。
2. 作者发起的长帖或线程首帖；必要时合并作者自己的连续补充。
3. 作者带引用发布，但自己的正文已经形成完整观点。

排除：

- 以回复他人为目的的内容。
- 纯转发或只有表情、附和语的引用。
- 缺少被回复对象就不知道在说什么的半句话。
- 私信、草稿、仅关注者可见内容，除非用户明确提供并授权处理。

## 2. 长度策略

- 约 220 个中文字符以内：尽量逐字保留。
- 约 220–520 字：先重排段落；每段 1–3 句，关键转折前后留空行。
- 超过约 520 字：压到 300–480 字，或拆成 2–4 张连续卡片。

长度只是信号，最终以 1080×1440 成品的手机可读性为准。

## 3. 压缩顺序

1. 删除重复解释、口头填充和不影响结论的旁枝。
2. 合并表达相同的句子。
3. 把过长的例子压成一句，但保留例子承担的论证作用。
4. 保留作者独有的比喻、梗、反差和结尾。

不得：

- 新增作者没有说过的观点、数字、经历或因果。
- 只留金句，导致上下文断裂。
- 把语气统一改成模板作者的风格。

## 4. 多卡切片

只有一张卡无法清晰承载时再拆分。每张结构为：

- 一句可独立理解的承接标题或上下文。
- 一个完整分论点。
- 必要时加 `1/N`、`2/N` 顺序标记。

最后一张必须保留原文结论。第一张不能只做标题而没有信息。

## 5. 选题排序

批量选取时优先：

1. 观点完整，有明确开头和结尾。
2. 有反差、具体例子或可复述的判断。
3. 对陌生读者也有价值。
4. 与近期已做卡片不重复。

热度只作辅助，不用高互动替代内容质量。
